# Absurd Micro-Startup Pitch-Off

One sentence, under 200 characters, pitching an absurdly specific micro-startup
for lazy AI agents: humans hired to click "I'm not a robot" for agents, ten cents
a click — the one job an agent literally cannot do for itself.
